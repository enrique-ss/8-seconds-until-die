# 8 Seconds Until Die

Um jogo de texto interativo onde você tem 8 segundos para explorar um quarto e se preparar antes que um intruso entre.

## Versão CLI (Terminal)

Para jogar no terminal:

```bash
node game-cli.js
```

## Como Jogar

- Você tem 8 segundos na fase de exploração
- Analise os objetos do quarto para descobrir itens e esconderijos
- Quando o tempo acabar, um intruso entrará no quarto
- Esconda-se e use itens para sobreviver e escapar

## Comandos

Durante o jogo, você verá opções numeradas. Digite o número da opção que deseja escolher.

## Lugares para se esconder

- Debaixo da cama
- Dentro do armário
- Atrás da porta

## Itens

- Taco de beisebol (na estante)
- Lençol (na cama)

## Condições de Vitória

- Fuga pela porta: o intruso deve estar atordoado ou ocupado em outro lugar
- Fuga pela janela: o intruso deve estar atordoado ou não mirando na janela

## Dicas

- Analise os lugares primeiro para desbloquear opções de esconder-se
- Pegue itens úteis (taco, lençol) durante a exploração
- Use o taco para atordoar o intruso e facilitar a fuga
- O lençol pode ajudar a esconder sua silhueta
